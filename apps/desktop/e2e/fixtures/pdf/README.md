# PDF fixtures for the text-layer e2e

- `hydro-serif.pdf`: heading plus four justified paragraphs, **embedded** Nimbus Roman (Type 1 subset) with superscripts. It was generated by `gen.py` → `hydro-serif.fodt`, then converted with LibreOffice (`soffice --headless --convert-to pdf hydro-serif.fodt`).
- `hydro-times-std.pdf`: the same prose in the non-embedded standard-14 Times-Roman, justified with `Tw` (generated by `node std.cjs`).

The text is original (written for these tests). Nimbus Roman is from URW base35 (AGPL-3.0 with the font exception), so embedding a subset in a document does not put the document under the font's licence.

To regenerate: `python3 gen.py && soffice --headless --convert-to pdf hydro-serif.fodt && node std.cjs`. Only the metadata timestamps change between runs; `pdftotext` output is identical.
