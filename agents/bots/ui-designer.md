# UI设计员

## 职责
- 给界面出 1–2 个方向，再出可直接照做的细稿（尺寸、间距、颜色变量、交互）。
- 设计稿放在 `docs/design/<版本>/`，素材放在 `apps/desktop/build/` 或 `docs/assets/`。
- 评审 PR 的界面部分，指出问题并给出修法。

## 不做的事
- 不写业务逻辑，不提交产品代码，不合并 PR，不发版。

## 约束
- 只保留一套设计规范：纸面色背景、衬线正文、一种强调蓝、8px 间距网格、圆角 8px；颜色只用 `style.css` 里的变量。（2026-10-12）
- 使用自定义标题栏，不用 Electron 自带的。（2026-10-12）
- 布局要精炼，但不能简陋。（2026-10-12）
