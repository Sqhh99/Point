# ④ 标记与一起问

版本：保持 0.1.1，不升。

## 做了什么
- **数据库 migration 003**：新建 `marks(id, doc_id REFERENCES docs(id) ON DELETE CASCADE, anchor_json, note, created_at)`，并按 `(doc_id, created_at)` 建索引。
  - 排在 001、002 之后，可以重复运行；从版本 2 升上来不会动已有数据。
  - 工作区每次打开连接时都会设 `PRAGMA foreign_keys = ON`（`workspace.ts` 里原来就有，这次补了测试），所以删除文档时会级联删掉它的标记。
  - 删除标记只删数据库里的行，不会删 `.point/captures` 里的截图文件。
- **锚点类型**：项目里原来没有锚点类型，这次在 core 里新建了 `TextAnchor` 和 `RegionAnchor`（`packages/core/src/marks`）。
  - `TextAnchor`：文字，可选 blockId、page、context。
  - `RegionAnchor`：sha、宽、高，可选 blockId、page。
  - 写入前都用 `parseAnchor` 校验，只保留已知字段。区域锚点的 sha 用 `isCaptureSha` 校验；这个函数已从 main 移到 core，main 的 `capture.ts` 重新导出，行为不变。
  - 数据库里被篡改或损坏的行在读取时会被跳过，不会原样返回。
- **core**：
  - `MarkStore`：标记的增删改查。
  - `buildBatchMessage`：「一起问」时生成一条用户消息，内容按勾选顺序排列。
  - `ChatMessage.parts`：文字和图片可以交错排列，`buildOpenAIBody` 按顺序发出。
- **IPC**：`marks:list`、`marks:create`、`marks:updateNote`、`marks:remove`。
  - 文档 id 和标记 id 都必须是 UUID 格式；创建标记时文档必须存在。
  - 区域标记的截图必须已经存在（用 `readCapture` 校验）。
  - 渲染进程不传任何路径。
- **一起问**：`tasks:run` 新增 `marks` 字段，传标记 id，最多 20 个。
  - 所有标记都必须存在，并且属于当前文档。
  - 文字标记作为文字段落，区域标记由 main 从校验过的 sha 读出图片，作为图片段落。整个问题是一条用户消息。
  - 模型不支持看图、又勾选了区域标记时，沿用 `no_vision` 拒绝，什么都不存。
  - 用户消息的 meta 里存了这批标记的快照，对话里的引用卡会按顺序列出这些标记。
- **界面**（按设计稿 v0.2，只用现有 CSS 变量）：
  - 松开选区后，选区上方弹出浮动条「问 AI · 标记 · 解读」。原来的「记笔记」「画图表」收进末尾的「⋯ 更多」里。
  - 框选截图松手后弹出同一个浮动条：「问 AI」把截图附到输入框，「标记」新建区域标记，「解读」直接带图解读。
  - 左栏新增「标记」组（组标题 11px 大写字距）。每项是复选框，加文字或 36×24 的截图缩略图，再加页码；点击会跳回原文，并给对应段落加 `--accent` 描边闪一下；悬停时显示 × 删除。底部按钮「一起问（n）」，n 为 0 时不可点。
  - 有标记的段落用 `--highlight` 底色高亮。
  - 一起问时，输入框上方显示「一起问 n 个标记」，可以移除。

## 测试
- 新增 `test/main/marks.test.ts`：
  - migration：重复运行、从 v2 升级、级联删除、文档不存在时拒绝。
  - 每次打开工作区 `foreign_keys` 都是 1。
  - 锚点：读写往返一致，会去掉多余字段；13 种非法锚点都会被拒；损坏的行会被跳过。
  - 一起问的消息：段落顺序正确，OpenAI 请求体里图片位置正确。
  - IPC：增删和校验；删除标记后截图文件还在；一起问的顺序和回答；模型不支持看图时拒绝且不落库；纯文字标记不需要看图能力；未知、属于其他文档、格式错误的标记 id 和非 ask 的任务类型都会被拒。
- 原有测试的调整：
  - migrate 两个测试里的表名列表加上了 `marks`。
  - 两个「后续 migration 失败」的回滚用例原来用 `CREATE TABLE marks` 当探针，现在 marks 表真的存在了，改用 `zz_probe`。
  - 原有 e2e 改成新的浮动条：「解读」，以及「更多 → 记笔记 / 画图表」。框选之后要先点浮动条上的「问 AI」。
- 新增 e2e：选中文字后点浮动条的「标记」会出现在列表里并高亮；再标第二条；倒序勾选两条后一起问，回答显示收到 2 个标记，引用卡按勾选顺序列出；点击标记能跳回原文。
- lint、typecheck 退出码都是 0。core 143 项通过；main 539 项通过、4 项跳过；e2e 13 项通过、1 项跳过（原有的、Linux 上系统加密不可用的用例）。
