# fix(ui): 工具条盖住选区外正文时翻到下方

#81 第一项。不改版本号。行首死点和拖过文档末尾另开 PR。

## 行为
- 默认仍在选区首行上方 8px。
- 若这个位置会压到选区外的正文（三击整行时最常见），改放到选区末行下方 8px。
- 翻下去之后如果还会压正文或会出视口，再夹进阅读器视口；没有传入正文盒子时，原有「上方空间不够才下翻」的行为不变。

## 改动
- `placeBar` 增加可选 `obstacles`；`Reader.measure` 把 `.pdf-line` / `.block` 里位于选区上方或下方的盒子传进去。
- 区域框选工具条的调用未改（不传 obstacles）。

## 验证
- unit：`placeBar` 原有用例保持；新增盖住上方正文则下翻、远处正文不影响、下方正文不影响、下翻后出视口则夹住、下翻后仍压正文但还在视口内则停在下方 8px；`outsideBodyRects` 丢掉与选区同一竖向范围的盒子。
- e2e：`pdf-embedded-fonts` 三击第 3 行，工具条在选区下方且不压第 1、2 行；三击第 1 行（上面没有正文）仍在上方。
